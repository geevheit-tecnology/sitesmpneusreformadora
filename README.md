# SM Pneus

Base institucional premium para reformadora de pneus, preparada para evoluir para plataforma digital com CRM, orçamentos, atendimento e área do cliente.

## Stack atual

- React + TypeScript + Vite
- CSS com tokens de design
- Serviços mockáveis para Analytics, WhatsApp, E-mail, Leads e Orçamentos
- Assets organizados em `public/assets`

## Comandos

```bash
npm install
npm run dev
npm run build
```

## Observação de backend

O prompt pede Laravel/PHP 8.3 como preferencial. Este ambiente não possui PHP/Composer, então a entrega atual implementa a camada web e deixa contratos, migrations e documentação para acoplamento posterior com Laravel + PostgreSQL.
